ITC 3 Controller

Supplied and serviced by Global Suntech in partnership with Swarco Technology, Denmark. A versatile, high-capacity traffic controller designed for complex intersections and integration with adaptive smart-city systems. Operating on a powerful Linux ARM-based platform with dual safety processors (EN61508 SIL 3), it delivers unmatched reliability and fail-safe operation.

Built for the future, it can manage all existing signal heads and control traffic with maximum safety under all conditions. Its integrated, easy-to-use interface gives engineers a flexible solution for configuration and confirming signal status.

KEY FEATURES
  • Cost-effective rack system – up to 24 signal groups in a single rack
  • VGA Touchscreen 800x480 – Easy to maintain and program.
  • Innovative Adaptive Traffic Algorithms – calculate flow to capacity for every cycle and optimize cycle time and green split for a single intersection.
  • ITC-PC Programming tool – a powerful 3D graphical programming tool that makes it easy to configure the controller, even with advanced adaptive programs.
  • Network & Compatibility: Seamlessly interfaces with all major global traffic management protocols, including SCATS, SCOOT, NTCIP, Omnia, and RSMP.

SW E100 Controller

Supplied and serviced by Global Suntech in partnership with Sinowatcher, Shenzhen, China. It is an adaptive traffic signal controller; a high-performance traffic signal control device designed for urban Intelligent Transportation Systems (ITS). It integrates adaptive, coordinated, and actuated control with multi-mode operation to dynamically optimize signal timing based on real-time traffic conditions.

It supports time-of-day scheduling, actuated/semi-actuated control, isolated adaptive control, and offline arterial and area coordination, centrally managed through a traffic control center. Optional functions include BRT transit signal priority, VIP and special-purpose vehicle priority, and pedestrian call control.
